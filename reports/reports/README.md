# Investigation Reports

This folder will contain reports from controlled lab investigations.

## Report Structure
Each report will include:

1. Summary — what triggered the investigation.
2. Evidence — relevant logs, accounts, hosts, and processes.
3. Timeline — events in chronological order.
4. Analysis — suspicious behavior and alternative explanations.
5. Verdict — conclusion, confidence, and supporting evidence.
6. Response — recommended actions and any lab actions performed.
7. Lessons learned — detection improvements and limitations.

## Evidence Guidelines
- Clearly label simulated lab activity.
- Use sanitized logs and screenshots.
- Distinguish observed facts from assumptions.
- Record uncertainty when evidence is incomplete.
