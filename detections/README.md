# Detection Rules

This folder will contain detection queries and their documentation.

## Planned Rules
1. Repeated failed logins followed by a successful login.
2. An account added to a privileged local group.
3. Suspicious PowerShell activity.

## Documentation for Each Rule
- Purpose
- Required logs and fields
- Detection query
- Test procedure and results
- Possible false positives
- Investigation steps
- Limitations

## Status
Planning only. No detection rules have been implemented or tested.
